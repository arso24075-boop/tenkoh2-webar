# AR UI実機検証済み安定版（ar-ui-mobile-tested-v1）

このフォルダは、展示用AR画面UI（戻るボタン・使い方モーダル・マーカー状態案内・
カメラエラー表示）を含む状態で、GitHub Pages上のスマートフォン実機による
動作確認が完了した時点の安定版スナップショットです。3Dモデル（GLB）交換前の状態です。

## 確認済み項目

- GitHub Pagesで正常動作確認済み
- スマートフォン実機で正常動作確認済み
- 戻るボタンが正常（AR画面からトップ画面`index.html`へ遷移）
- 使い方モーダルが正常（開閉、背景タップ・Escキーでの閉じる操作を含む）
- マーカー状態に応じた案内表示が正常（準備中／カメラ起動中／未認識案内／検出／定常表示／再認識案内の切り替え）
- カメラ、マーカー認識、実寸、傾き、回転が正常
- 3Dモデル交換前の安定版

## 含まれるファイル

- `index.html` … トップ画面
- `ar.html` … AR画面（展示用UI込み）
- `css/landing.css` … トップ画面で使用しているCSS
- `css/ar-ui.css` … AR画面UI（戻る/使い方ボタン、ステータス、モーダル等）のCSS
- `js/ar-ui.js` … AR画面UIの表示・状態管理JavaScript
- `js/spawn.js` … AR画面で使用している出現アニメーション制御JavaScript

※ AR画面のカメラ映像自体を表示するための基本スタイル（`ar.html`内の`<style>`タグ、
　 body margin/overflowのみ）はHTMLに直接埋め込まれているため、対応する独立した
　 外部CSSファイルはありません。
