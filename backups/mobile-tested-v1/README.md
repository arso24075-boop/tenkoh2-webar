# スマートフォン検証済み安定版（mobile-tested-v1）

このフォルダは、MacBookとスマートフォン実機の両方で動作確認が完了した時点の
安定版スナップショットです。3Dモデル（GLB）交換前の状態です。

## 確認済み項目

- MacBook Safariで正常動作確認済み
- スマートフォン実機で正常動作確認済み
- トップ画面からAR画面へ正常に遷移
- 背面カメラが正常に起動
- カスタムマーカーを正常に認識
- 灰色の箱が正しい実寸比で表示
- 高さ、20度の傾き、20秒回転が正常
- 出現アニメーションが正常
- 5秒以内の追跡切れでは再演出しない
- 5秒以上見失った場合だけ再演出する
- GitHub PagesのHTTPS環境で正常動作確認済み
- 3Dモデル交換前の安定版

## 含まれるファイル

- `index.html` … トップ画面
- `ar.html` … AR画面
- `css/landing.css` … トップ画面で使用しているCSS
- `js/spawn.js` … AR画面で使用しているJavaScript

※ AR画面のCSSは`ar.html`内に`<style>`タグとして直接埋め込まれているため、
　 対応する独立した外部CSSファイルはありません。
