# てんこう2 WebAR 最小プロトタイプ

A-FrameとAR.jsを使用した、マーカー型WebARの最小プロトタイプです。
15cm角のカスタムマーカー（`tenkoh2-marker.patt`）をスマートフォンのカメラで認識すると、
実寸30cm×20cm×10cmの灰色の直方体がマーカー上に表示されます。

今回のスコープは「マーカー認識」と「実寸確認」のみです。
GLBモデル・光の粒子・傾き/回転アニメーション・フェードイン・複雑なUIは含まれていません。

## ファイル構成

```
.
├── index.html          # ARシーン本体（A-Frame / AR.jsの読み込みとマーカー・直方体の定義）
├── css/
│   └── style.css        # 全画面カメラ表示、VRボタン/デバッグUIの非表示、案内テキストのスタイル
├── js/
│   └── ar.js             # markerFound / markerLost イベントで案内テキストを切り替える処理
└── assets/
    └── markers/
        └── tenkoh2-marker.patt   # カスタムARマーカー（pattern形式、実寸15cm角）
```

## 各ファイルの役割

- **index.html**
  A-Frame本体とAR.js（`aframe-ar.js`）をCDNから読み込み、`<a-scene>`内に
  pattern形式のマーカー（`size="0.15"`＝15cm）と、その上に表示する直方体
  （幅0.30m×高さ0.10m×奥行0.20m、色は灰色）を定義しています。
  直方体はマーカー面から底面が5cm浮くよう、中心のY座標を0.10mにしています。
  VRボタンは`vr-mode-ui="enabled: false"`、AR.js標準デバッグUIは
  `arjs="debugUIEnabled: false"`で無効化し、`facingMode: environment`で
  背面カメラを優先させています。

- **css/style.css**
  カメラ映像とARシーンを画面全体に表示するための基本スタイルと、
  万が一表示されてしまった場合の保険としてVRボタン/デバッグUIを
  `display: none`で隠すルール、画面下部の案内テキストの見た目を定義しています。

- **js/ar.js**
  マーカーの`markerFound`（認識時）／`markerLost`（見失った時）イベントを監視し、
  画面下部の案内テキストを「カードのマーカー全体を映してください」⇔
  「マーカーを認識しました」で切り替える最小限のロジックです。
  動作確認用に必要最低限の`console.log`を出力します。

- **assets/markers/tenkoh2-marker.patt**
  既存のカスタムARマーカー（pattern形式）。実物の印刷サイズは15cm角を想定しています。

## ローカルでの起動方法

AR.js（カメラ映像の取得、マーカーファイルの読み込み）は`file://`での直接オープンでは
動作しません。必ず簡易HTTPサーバー経由で開いてください。

例：Python標準ライブラリを使う場合（npmは使用しません）

```bash
cd tenkoh2-webar
python3 -m http.server 8000
```

ブラウザ（PCのChrome/Safari等）で以下を開いて、カメラ許可ダイアログや
画面下部の案内テキストが表示されることを確認してください。

```
http://localhost:8000/
```

PC単体ではマーカーを印刷物にかざせないため、まずは「エラーなく起動し、
カメラ映像と案内テキストが表示されること」の確認を目的としてください。

Live Server（VS Code拡張）など、他の静的サーバーでも同様に動作します。

## スマートフォンでの確認方法

カメラAPI（`getUserMedia`）はセキュアコンテキスト（HTTPS、または`localhost`）でのみ
動作します。スマートフォンの実機で確認する場合は、以下のいずれかの方法でHTTPSの
URLを用意してください。

1. **同一ネットワーク＋トンネリングサービスを使う場合（推奨・手軽）**
   `ngrok`や`Cloudflare Tunnel`等でローカルサーバーをHTTPS化して公開し、
   発行されたURLをスマートフォンのブラウザで開きます。

   ```bash
   # 例：ngrokを使う場合（別途インストールが必要）
   ngrok http 8000
   ```

2. **GitHub Pages等の静的ホスティングにデプロイする場合**
   本プロジェクトは静的ファイルのみなので、GitHub Pages・Netlify・Vercel等に
   そのまま配置すればHTTPSのURLが得られます。

スマートフォン側の確認手順：

1. iPhoneはSafari、AndroidはChromeでHTTPSのURLを開きます。
2. カメラ使用許可のダイアログが出たら「許可」します。
3. 画面下部に「カードのマーカー全体を映してください」と表示されることを確認します。
4. 印刷した`tenkoh2-marker.patt`のマーカー（15cm角）全体を画面に収めます。
5. マーカーを認識すると案内テキストが「マーカーを認識しました」に変わり、
   マーカー上に灰色の直方体（実寸30cm×20cm×10cm、底面が5cm浮いた状態）が
   表示されることを確認します。
6. マーカーを画面外に外すと、案内テキストが元の文言に戻ることを確認します。

### 注意点

- 背面カメラを優先する設定（`facingMode: environment`）にしていますが、
  端末によっては起動時のカメラ許可ダイアログで選択を求められる場合があります。
- マーカーは実際に印刷し、15cm角のサイズを保って平らな場所に置くと
  認識精度が安定します。
- 認識しない場合は、照明を明るくする・マーカーとの距離を30〜60cm程度にする・
  マーカー全体（白い外枠を含む）が画面に収まっているかを確認してください。
